# 上传文件处理

DevStore 当前不运行 ClamAV 或其他恶意软件扫描器。付款凭证上传仅接受完整解码的 PNG/JPEG，单文件不超过 5 MiB，边长不超过 8000，像素总数不超过 2000 万；应用在有界阻塞线程池中解码后保存到私有对象存储。API 只允许订单所有者和管理员读取，响应使用图片 MIME、`nosniff` 和 `private, no-store`，不暴露对象存储 URL。

文件对象维持 `quarantined` 状态。管理员须通过后台鉴权页面查看凭证，再人工核对转账金额、收款记录和订单归属；不要打开图片内链接、执行文件内容或把上传内容转发到公开渠道。图片格式和像素限制只能降低解析器和资源消耗风险，不能替代恶意软件扫描。

未关联到付款凭证的孤立对象由清理任务在保留期后回收。若未来引入云端扫描，应保持私有隔离，只有扫描结果明确通过后才允许进入可交付状态；超时、未知结果和服务故障都应拒绝放行。
