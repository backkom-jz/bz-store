## 整体审查与处理

独立只读审查无 Critical，发现三项 Important，均已处理：

1. MySQL URL 的 `socket` 参数可能绕过已校验主机。Node 回归先观察“未拒绝”的失败，再禁止该参数（含编码参数名）；SSL 配置参数仍允许。单测通过。
2. 既有工单验收先锁工单、退款先锁订单，可能形成死锁。统一验收为先查不可变关联、锁订单、锁工单并重新校验状态；新增并发 HTTP 用例，已编译，真实 MySQL 效果待云端执行。没有把静态推导或编译称作数据库 RED/GREEN。
3. 既有 E2E 动态码计数只保存在单个 worker 内，桌面/移动项目可能重放。改为在私有凭据文件记录已占用计数，单 worker 顺序执行下跨项目保留；新增真实临时文件回归，先失败后通过。
